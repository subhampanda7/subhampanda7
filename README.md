## 👨‍💻 About

Backend engineer focused on **distributed systems that stay fast and correct under load**. I design and ship Java + Spring Boot microservices that process millions of events, lean on Kafka for asynchronous decoupling, Temporal for long-running workflow orchestration, and Redis for latency-critical paths.

- ⚡ **Scale** — high-throughput services, async pipelines, and back-pressure-aware consumers
- 🧩 **Architecture** — event-driven design, service decomposition, idempotency, and failure recovery
- 🚀 **Performance** — query tuning, caching strategy, and latency profiling with measurable wins
- 🤖 **AI engineering** — LLM-assisted development, RAG patterns, and MCP-based tooling integrated into real delivery workflows
- 🎯 Interested in **senior backend / distributed systems** roles where reliability and throughput actually matter

## 🛠 Engineering Focus

| Area | What I Build |
| :--- | :--- |
| **High-Throughput Services** | Low-latency REST APIs and async processors built for sustained production traffic |
| **Event-Driven Systems** | Kafka producers/consumers, retry & DLQ strategy, exactly-once and idempotent processing |
| **Microservices** | Cleanly bounded services with resilient inter-service communication and graceful degradation |
| **Workflow Orchestration** | Durable, long-running business workflows with Temporal — retries, timers, and compensation |
| **Caching & Performance** | Redis-backed caching layers, hot-path optimization, and database query tuning |
| **Distributed Systems** | Consistency trade-offs, concurrency control, fault tolerance, and observability by design |
| **AI-Powered Dev Workflows** | LLM/RAG-assisted engineering, MCP integrations, and AI tooling for code, review, and docs |
